## 传奇视觉语法（2026-11-18 实拍实证版 —— 覆盖之前所有版本）
- **教训：研究特效必须看图，不能靠词条推演。** 词条版结论有四处是错的（见下）。
- 抓法：`image.so.com/j?q=<关键词>` 拿 `"img"` 直链 → 过滤 `.gif` → curl 下载；
  同一 IP 连打会被限流（返回 3.5KB 空壳），每次请求间隔 8~20s 重试。
- **六条铁律（逐帧实测得出）**：
  ① 一招一形（形状由判定决定，不叠第二形状）；② 一招一色相 + 1 白高光
  （火是红→橙→黄**同色相明度渐变**，不是多色并列）；③ **主体要厚**（刀光 8~13px
  实心楔形带白芯、火焰多层火舌、柱子是实体，**元素少但单个必须大**）；
  ④ 三段节奏（起手 1/3 帧画面留空 → 主体一帧到全盛 → 消散碎 8~14 粒或直接没）；
  ⑤ 碎屑只在主体边缘 ≤14；伤害数字周围留空不叠特效；受击不用全身白闪；
  ⑥ **一招 10~18 帧（0.4~0.8s）** —— 传奇主流 8~14 帧。
- **词条版被推翻的四处**：①「传奇特效素」错 —— 传奇元素**又厚又大**，
  「素」指元素数量少；②「一招一色」不精确 —— 是 1 色相明度渐变；
  ③ 漏了**时长**（我们 90~120 帧慢一倍还不止）；④ 漏了范围招招牌手法
  （**多根同形落柱依次砸下 + 地面法阵**）和「召唤物是实体素材」。
- 族色（实证）：战士橙红（刀上火/火焰弧）/ 法师蓝紫（雷柱）/ 道士青绿（施毒阵）/
  刺客冷白（暗器）。法器/令旗/魂幡只作演出意象。

## 已定案的空间语言（防再犯）
- 贴地平面一律 `fy = 0.32` 压扁椭圆：`x = cx + cos(a)*R`、`y = cy + sin(a)*R*fy`；月轮本体也是椭圆。
  「手在体外」用椭圆空间半径 `hypot(x, (y-cy)/fy)`，不用屏幕欧氏距离。
- 枪族「双手一杆枪 + 手 / 杆 / 缨 / 尖可见」，**枪身不压扁**，只有地面尘环 / 范围圈用贴地椭圆；
  `weapons.js` 枪 = 短杆 + 束红缨，`staff` 是棍；`mage` 是法杖（`ranged`），`dart` 是暗器。
- 画布内 `ORIGIN={x:76,y:106}` / `ENEMY={x:138,y:102}`：文字 y 超过 `ENEMY.y-80` 会顶出画布被裁。
- **人枪 / 人刀不许脱节**：击退类招式要让人物跟着前压（`spear_2 followLunge 40px`），否则枪尖竖在
  头顶、怪被推到右边，读成「戳空气」；判定帧锚点必须落在怪物身上。
- 红压红会糊：枪线压在红色怪身上靠「灼红 + 1.2px 白芯」的色差读，不靠加亮；末端用实心细锥，
  不用开口「>」箭头（会读成一支红箭）。
