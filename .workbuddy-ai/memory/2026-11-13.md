（`actor:'stationary'` / `plane:'ground'` / `hitAnchor:'blade tip ∩ enemy shoulder'`），用户看到的就是这一块。

### 做法（只动渲染层，零改招式定义）
- 在 `renderProto()` 里加两层映射：`PROTO_LABEL`（键名→中文）+ `PROTO_PATH_LABEL`（`path.key`→中文，
  解决同名不同义：顶层 `from` 是「数据来源」，`motion.from` 是「起始帧」）。
- `PROTO_VALUE` 补 20 招全部枚举中文（刀族后四招 / 枪族后八招的 `kind`、`grip`、`trajectory`、`anchor` 全在内）。
- `protoVal()` 加三档兜底：`boolean → 是/否`、`null/undefined/'' → —（无）`、空数组 → —（无）。
- 「可写入覆盖表的字段」保留英文原键名 —— 那是导出契约，一个字都不能改；原始 JSON 收进 `<details>` 折叠。
- `hand` 与 `grip` 值相同时只渲染一行（枪族 / 双刃都这样，否则「持械方式」刷两遍）。
- 命中事件表补 `残影 N / 第 N 波 / 伤害 / 必暴 / 判定字 / 挑飞`；状态事件表补 `角标 / 射程 / 穿透 / 维持帧`。

### 顺手修的两个过期写死
- 页头进度徽章原写死「已完成 16 / 80 · 第 4 批放大送审」→ 改成 `progressInfo()` 按 `BATCHES` 状态实时算，
  现在是「已建 20 / 80 招 · 你已通过 12 招 · 第 3 批返修送审 等你审核」。
- 页头说明段落原写「默认停在第 4 批 · 枪族前 4 招」→ 改成第 5 批枪族后四招的真实口径。

### 自检（`tools/art-motion.js` 新增 ⑪ 四条，共 220 PASS / 0 FAIL / ok=true）
- 20 招 protocol 每个键都要有中文标签（除 `override` 子树）；
- 每个字符串取值都要有中文映射（招式 id / 文件路径 / 纯数字 / 本身含中文的说明句除外）；
- 面板正文不许出现裸 `true` / `false` / `null`（原始 JSON 折叠区除外）；
- 页头徽章必须含「/ 80」。
- `__protoMap` 改成 getter 暴露（`PROTO_PATH_LABEL` 定义在后面，直接取值会拿到 undefined）。

build.js / dist` 与线上产物零改动，未提交、未打包、未发布。临时补丁脚本已清。
