## 9. 本地双击与触屏适配（v3.1）

### 9.1 为什么双击 index.html 只能看到菜单

不是 bug，是浏览器的规矩：`file://` 下取 ES module 会用 `origin 'null'` 去请求，被 CORS 直接拦掉，
`game.js` 一行都没执行 —— 所以 HTML/CSS 的菜单还在，但按钮的 `onclick` 从来没绑上去。
控制台原文：`Access to script at 'file:///…/game.js' from origin 'null' has been blocked by CORS policy`。

处理办法：
- **不再直接写 `<script type="module" src>`**，改由一段内联脚本按协议分流：
  - `http/https`：动态注入 module，走原来的 ESM 源码（开发流程不变）。
  - `file://`：加载同目录的 `xiaoyao-bundle.js`（经典脚本不受这条限制）。
- `build.js` 负责把 `three.module.js` + 9 个模块按依赖序塞进一个 IIFE，产出：
  - `xiaoyao-bundle.js` —— 经典脚本，`index.html` 双击时自动加载。
  - `逍遥行.html` —— 单文件版（HTML/CSS/JS 全内联），可以直接发给别人，双击即玩。
- 改了源码想继续双击玩，跑一次 `node build.js` 即可；跑 `node server.js` 则不用打包。

> 坑：`String.replace` 的替换串里带 `$&`、`$'` 会被当成替换模式，把打包结果搅碎（表现为
> `SyntaxError: Invalid or unexpected token`）。改用函数返回替换内容才安全。

### 9.2 触屏操作

| 区域 | 功能 |
|---|---|
| 左下（热区 148×104） | 虚拟摇杆。**以按下的位置为圆心**，不是死板固定；有 6px 死区，轻推慢走、推到底全速 |
| 右下 | 斩（大键，金边）/ 气 / 舞 / 雷 / 闪 / 丹，冷却用扇形遮罩直接画在键上 |
| 右上（小地图下方） | 囊 / 道 —— 手机上按不到 Tab / T，给行囊与道行面板留的入口 |

- 判定：`?touch=1` 强制开、`?touch=0` 强制关，否则按 `ontouchstart` / `maxTouchPoints` 自动判断。
- 左摇杆与右按键用 `pointerId` 分别跟踪，左手推杆时右手能连点攻击。
- 触屏下底部技能栏让位（`skillRects` 清空）、键盘提示文案隐藏、底板从 44px 收窄到 18px。

  竖屏时画面下方浮一条"建议横屏"提示，横过来自动消失。

## 10. 昼夜系统（v4 · S3 批次 A）

一天 14 分钟，四段：**卯（晨雾 2 分）／午（白昼 6 分）／酉（黄昏 2 分）／子（黑夜 4 分）**。
目标不是"加一层滤镜"，而是让时间变成**玩法开关**：什么时辰出什么怪、什么时候刷宝最划算。

### 10.1 视觉

色罩走**离屏合成**，不是直接往画布上盖：

1. `lightC`（480×270）整屏铺一层氛围色；
2. `destination-out` + 预渲染光晕贴图，把灯的位置"挖"出来；
3. 一次性 `drawImage` 到「世界之上、HUD 之下」。

好处：HUD、伤害数字、小地图始终是亮的，读数值不受天色影响；而世界真的会暗下去。

- **光源**：玩家自带一盏（半径 82 —— 这就是夜间可视半径）、6 处营地篝火、40 座石灯、土地庙神龛。
  火苗用两个不同频率的正弦叠加做呼吸，不是死循环。
- **白昼零开销**：`lightAt()` 白昼返回 `a=0`，`drawDayNight()` 第一行就 return，一帧都不多画。
- 灯光之上还有一层暖色 `lighter` 叠加，否则灯只会"透"不会"亮"。

> **反直觉的坑**：色罩**不能**当滤镜给低 alpha。青绿底（46,107,103）上叠 alpha 0.17 的橙色，
> 结果只是脏灰绿，肉眼完全读不出黄昏。必须给到 **0.4~0.7**、并且让色罩的红通道**高于**底色的绿通道，
> 才会真的变暖。夜里同理，0.4 看着像"水下"，0.7 才是"天黑"。
>
> **第二个坑**：`KEYS` 首尾必须同值。漏掉 `t: 1.000` 那一帧，`lightAt()` 在 t>0.975 时落到兜底分支返回纯白 a=0，
> 每天最后 21 秒会闪一下白。

### 10.2 玩法

| 时辰 | 效果 |
|---|---|
| 卯 · 晨雾 | 打**尚未察觉你**的怪伤害 ×1.5，伤害数字显示「偷袭」并放大 —— 清营地最划算的时候 |
| 午 · 白昼 | 原画、无加成 |
| 酉 · 黄昏 | 营地开始补怪，野兽成群 |
| 子 · 黑夜 | 营地补怪 70% 概率改出阴物（阴魂/火鸦/影刺客/符傀）；**稀有掉落 +40** |

- **打坐**（`F`，土地庙旁）：推进一个时辰、回满真气、回 25% 气血，配 0.9s 一呼一吸的黑幕过场。
  它是这套系统的节奏器 —— 打不过就坐下熬过去，想占晨雾的便宜就跳回卯时。
- 触屏端「坐」键只在土地庙旁才浮出来，平时不占位置。
- 跨时辰会敲钟（`audio.js` 的 `bell`：卯 520 / 午 780 / 酉 620 / 子 330 Hz，叠五度与八度正弦 + 木鱼噪声）。

### 10.3 HUD 日晷

小地图正下方 78×22 一条：`时辰名 · 副名` + `第 N 日` + 分段进度条（3 道段界刻度）。
进度条读的是**本时辰还剩多久**，不是全天的进度 —— 玩家真正关心的是"离天黑还有几分钟"。

### 10.4 存档

`SAVE_KEY` 升到 `xiaoyao-save-v5`，多存 `clock: {t, day}`。老档（v4 及更早）读进来会给回开局上午（`t=0.18`），不会因为缺字段崩掉。

## 11. 青云集（v5 · S3 批次 B）

一片 22×14 格（352×224 px）的围墙聚落，落在世界坐标 `(608,704)–(960,928)`，南口开 80px 宽的牌坊。
它要解决的不是"多一个场景"，而是让野外有一个**能回去的地方**：走进去，天就开始按人的作息运转。

### 11.1 为什么整座村子是程序化画的

建筑是"大件"，112×78 的点阵手敲不现实，四栋楼的木纹、瓦楞、门窗一旦各画一套就会像素材拼盘。
所以 `village.js` 里只有六个构件，四家共用：

| 构件 | 作用 |
|---|---|
| `roof()` | 梯形瓦顶 + 瓦楞 + 翘角 + 鸱吻，可换瓦色 |
| `wallBox()` | 白灰/土坯墙 + 墙基 + 角柱 + 上枋 |
| `windowBox()` | 格窗（金色窗棂） |
| `doorBox()` | 门洞 + 门簪 + 门槛石 |
| `signBoard()` | 匾额：不写汉字（4px 的字谁也读不出），用三块金印的间距表达"这是块招牌" |
| `lantern()` | 红灯笼 |

四家只在装饰上分家：客栈挂招幌、药铺檐下晾药、铁匠铺敞着炉火与铁砧、酒馆插酒旗。
一条街看过去是"同一批匠人盖的"。

### 11.2 石板街与碰撞

- 新增**地块 5 = 石板街**：错缝 8px 块 + 1px 缝 + 冷暗底色（`#4C4A3C`）+ 苔/土点缀。
  第一版用的是"同色方格 + 稀疏随机点"，远看像贴了瓷砖，改成错缝才有石板的味道。
- 碰撞只把建筑**墙脚 20px** 设成实心。整栋设实心会把村子变成四个大方块，绕背走位全被卡住；
  屋身靠 `renderOrder = 1000 + y` 自然遮挡，玩家从背后走过去时被屋檐盖住，观感反而对。
- 南北向的围墙单开一张 `makeWallSide()`（8×16 窄带，左亮右暗）。
  正交无俯角的相机画不出"侧面"，硬套正立的 16×14 瓦片会变成一截梯子。

### 11.3 四家铺子与作息

`SHOPS` 里每家一句 `line`、一句 `closed`、一组 `openWhen`：

| 铺子 | 掌柜 | 营业 | 卖什么 |
|---|---|---|---|
| 云来客栈 | 柳三娘 | 通宵 | 住店 20 银两 / 热汤面 5 |
| 济世堂 | 孙伯 | 卯·午·酉 | 回春丹 12 / 大还丹 40 / 清心散 18 |
| 张家铁铺 | 张五 | 卯·午·酉 | 借炉（进铁匠台）、变卖凡品/精品 |
| 醉仙楼 | 阿七 | 午·酉·子（三更额外打烊） | 竹叶青 6 / 烧刀子 14 / 打听传闻 4 |

- **打烊不是装饰**：打烊时面板只报营业时辰、一个按钮都不给；窗灯不亮、掌柜回屋。
  玩家第一次意识到"世界有时间"，往往是从"店关门了"开始的。
- **掌柜**：四个 14×19 的 NPC 立在自家门边，1px 呼吸起伏；`shopOpenNow()` 决定在不在。
- **醉意**：酒直接乘进 `rollDamage()`（+15% / +25%），配 120 秒计时 —— 便宜、猛、有代价。
- **住店**写 `player.rested`，从此死亡回客栈而不是土地庙。这是整个村子最实在的回报。

### 11.4 安全区

村子必须是安全的，否则"回家"这件事没有意义。四层拦截：

1. 玩家在村内 → 敌人 `aggro` 强制为 `false`，追到墙根的会自己散回营地；
2. 敌人移动统一走 `eFree = canStand && !inVillage`；
3. `blinker`（阴魂）瞬移**先算落点再挪**，落点在村里或墙里就留在原地；
4. 村外射进来的箭矢/法术球在墙根被弹掉（配一小簇绿光）。

> **这是本批最值得记的一个 bug**：阴魂的瞬移原本直接写 `e.x = player.x - cos(a) * 34`，
> 完全没有落点校验。玩家站在村里，它就闪进村里 —— 表现为"白昼的石板街上凭空出现一只黑色小生物"，
> 用对象探针查还查不到（它不是 `objects`，是 `enemies`）。凡是"直接赋值坐标"的地方，都必须补校验。

### 11.5 验收

- `?dev=1`：**94 pass / 0 fail**（本批新增 25 条：营业时间 / 打烊无灯 / 打烊不给买 / 买药扣钱 /
  住店过夜回满扣钱存档黑幕 / 传闻 / 醉意 / 铁匠铺先开摊位再借炉 / 变卖换银两 / 围墙挡人 / 牌坊口可过 /
  房屋墙脚挡人 / 村内不刷怪 / 阴魂不闪进村 / 进村不被盯上 / 掌柜按作息上下班 / 死后回客栈 / 扣两成银两）。
- `tools/touch.js` 手机横屏：走到药铺门口「谈」键浮现并点开面板、远处不显示、住店过夜到卯时且扣 20，`ok: true`。
- 截图：白昼四家全开（四位掌柜各就各位）、子时只剩客栈亮灯、铁匠铺摊位面板排版。

## 12. 村民、对话与侠名（v5 · S3 批次 C）

批次 B 只让村子"能回去"，这一批才让它"有人住"。

### 12.1 谁在街上

七个人 + 四个掌柜 + 一个货郎。每人一张作息表，到点出现、到点消失：

| 人 | 身份 | 出现的时辰 | 手上的家伙 |
|---|---|---|---|
| 老周 | 更夫 | 子 | 灯笼 |
| 阿宝 | 村童 | 卯·午·酉 | 双髻（11×15 的画法） |
| 崔婆婆 | 老妪 | 卯·午 | 拐杖 |
| 石大 | 樵夫 | 酉·子 | 背上柴捆 |
| 柳先生 | 说书人 | 午·酉 | 折扇 |
| 玄阳子 | 游方道士 | 午 | 拂尘 |
| 王二 | 醉汉 | 酉·子 | 酒葫芦 |
| 赵四 | 货郎 | 午·酉 | 担子（走摊位 UI，不占街道） |

**分人的办法不是加颜色，是剪影**：头分六种（发髻 / 斗笠 / 方巾 / 道冠 / 歪帽 / 头巾），
手分四种（灯笼 / 柴捆 / 折扇 / 拂尘 / 葫芦 / 担子 / 拐杖）。远看一团墨也能认出这是谁。

小孩单独画（11×15，头占一半）。14×19 的骨架压不出"矮"——硬压只会变成寿星。

作息不是动画，是**读表的替代品**：子时街上只剩更夫和醉汉，酉时酒馆门口挤四个人，
玩家不用看日晷就知道几点了。切换时用 0.4 秒淡入淡出，人不是"啪"地刷出来的。

### 12.2 对话

`#talk` 面板，和商铺面板同一套皮：

- **打字机**：26ms 吐 2 字。点一下正文立刻给全 —— 急着看结果的人不该被动画拖住。
- **选项**：「打听」+ 该 NPC 的专属动作（问路 / 逗他 / 送药 / 听一段 / 求符 / 搭话）。
  打完听之后「打听」消失，换那句答话留在屏幕上。
- **记忆**：每人记 `spoke` 次数，招呼语按次数轮换。第三面说「嗐，又是你」——
  这比任何数值都更像"他记得你"。
- **按键优先级**：`interact()` 先认人再认柜台，两边都在范围内就比距离。
  HUD 提示用的是同一套判断，不会出现"提示说找老周、按 E 却开了铺子"。

### 12.3 侠名

五档，`fame` 0~200：

| 档 | 门槛 | 说书人讲什么 |
|---|---|---|
| 无名小卒 | 0 | 讲三十年前那个背刀的年轻人 |
| 初露锋芒 | 5 | 讲"近来野地里出了个后生" |
| 小有名气 | 15 | 讲"一晚上清了半个山头" |
| 一方豪侠 | 30 | 讲"黑风寨不敢下山了" |
| 名动江湖 | 60 | 讲"报上名号，山贼让路" |

怎么涨：精英 +2、首领 +8、**循传闻寻到地头 +3**、给崔婆婆送药 +6。
杀十只野狗不会让人记住你，斩一个寨主会 —— 所以普通怪一点不给。

怎么用：名望过 10 才开始让价，每点 0.25%，封顶 15%（八五折），面板上把原价划掉。
定这么淡是因为"买东西便宜"会直接改写刷装备的节奏，宁可少给。侠名同时挂在行囊面板上，
带称号和让价百分比。

### 12.4 传闻闭环

传闻仍然只有**一个槽**（`rumor` 一个变量）。做成列表会让小地图变成任务日志；
"你只能记住一件听说的事"，反而更像人。谁给的都覆盖同一个槽。

走到问号 52px 内 → 弹出「寻到 XX · 侠名 +3」，问号消失。这样传闻才算闭环 ——
否则它永远只是地图上一个不会兑现的符号。

### 12.5 验收

- `?dev=1`：**110 pass / 0 fail**（本批新增 16 条：午时街上有人 / 子时换一批 / 走近认人 /
  按 E 认人不认柜台 / 面板打开 / 打字机逐字吐 / 点一下跳过 / 打听换一句 / 作别关窗 /
  侠名八五折 / 说书人换段子 / 送药得人情 / 求符扣钱回真气 / 循传闻 +3 / 货郎卖精铁 / 存档记侠名）。

## 13. 青云古洞（v6 · S4）

批次 A/B/C 让世界"有时间、有人住、有人说话"。这一批做的是另一半：
**一个能反复刷、每次略有不同、值得走一趟的地方。**

### 13.1 为什么不做独立场景

换场景要备份 `tiles`/`solid`、快照整张 1536×1152 的地面 canvas、把树石房屋的
mesh 全藏掉再放回来——代价远大于收益，而且以后每加一个场景就要再写一遍。

所以古洞直接**占用世界地图上一块矩形**（格 4..34 × 39..67，即 480×448 px），
把这块地的 `tiles` 重写一遍。相机、碰撞、小地图、掉落、光照全部复用，一行没改。

代价是：玩家在洞里，地图上那块地确实是"真的被改了"。这条代价被**黑暗**抵掉了——
洞里可视半径 112px，连隔壁房间都照不到，谁也看不见重排。

> 为此把乱葬岗从 (23,54) 挪到 (24,30)：它正好压在山体上。

### 13.2 生成

房间乱放 + 最近邻连线。不追求"完美地牢"，要的是**每次不一样但一定连通**——
玩家不该因为随机数卡死在某个角落。

- 入口房固定在底边居中：第一眼必须是"一间屋"，不是一条不知通向哪的走廊。
- 房间 5~9 × 4~6 格，留 2 格缝（贴在一起会连成一片空地，失去层次）。
- 走廊铺 **2 格宽**：1 格在 16px 的格子里等于让玩家贴墙蹭，战斗时一个后撤步就卡进死角。
- 房间放在 x/y ∈ [2, W-3]：最外两圈必须留成实心岩。只留一圈时，玩家贴着墙站，
  视野会越过 16px 的岩层直接看到洞外的草地——那一抹青绿会毁掉"在洞底"。
- 最深处 = 离入口最远的房间，放地脉裂口（第 1、2 层）或洞主（第 3 层）。

连续 240 次生成（3 层 × 80 种子）全部连通，房间 6~10 间。

### 13.3 洞窟怎么画

- **地面**：冷灰石底色 + 三层色阶碎石 + 靠墙一圈暗 + 墙根青苔 + 偶尔一摊积水。
  积水是洞里唯一会反光的东西，一颗就够撑起"潮湿"。
- **岩壁**：全黑不行。正交俯视没有高度，唯一的立体感来自"朝南那一面亮起来"——
  墙格底部 8px 画立面，底部 1px 高光收边，立面下再压一道影把墙和地焊住。
  但墙身若全黑，就只剩一条悬空的横梁，所以本体给到 `#1E1F29`。
- **地板四面都收暗边**（不只上左右）：四面收，地才像"凹下去的坑"，
  而不是一块浮在暗处的板。
- **山体影**：区域**之外**上/左/右三面压 60px 渐变黑，洞里往外看是山岩不是草地。
  洞口那一面不压——那是走进去的路，压黑了会像洞口被封死。

### 13.4 三层与节奏

| 层 | 房间 | 怪池 | 出口 |
|---|---|---|---|
| 1 | 7~8 | 山贼 / 恶犬 / 赤练蛇 / 火鸦 | 地脉裂口 → 第 2 层 |
| 2 | 7~9 | 山魈 / 阴魂 / 弓手 / 符傀 | 地脉裂口 → 第 3 层 |
| 3 | 7~10 | 壮汉 / 石敢当 / 影刺客 / 阴魂 + **洞主** | 回地面（入口房） |

- **清层才开裂口**。地宫不大（十几只怪），清起来不累，但"还有几只"这个数字
  一直挂在 HUD 上——刷装备的人最需要这个数。
- 怪量按**房间宽度**给（宽房 3 只、窄房 2 只），不按层数堆。第 3 层 25 只怪
  挤在黑暗里，玩家感受到的是烦，不是难。深处的威胁要来自"更强"。
- 层数加成 `1 + 0.45 × (层-1)`，配 `spawnEnemy` 自带的等级缩放。
- 第 2、3 层的**洞口是封死的**。不封的话玩家能一路从地脉深处走回野外，三层就白做了。
- 死在洞里 = 这一趟白跑，`respawn()` 里直接重排。

### 13.5 洞主与宝箱

洞主「岩魈」是石胎成精，18×20 点阵：两角、红眼、胸口紫裂。
在黑暗里它本来只剩两只角——所以额外套一圈紫环（`e.ring`），
让玩家在"看清它"之前先读懂"这是首领"。

宝箱锁在清层之后。大箱（第 3 层）保底 R2 起、必给 3 件、外加 180±60 银两与 12 精铁。
箱子摆在洞主**身侧**而不是正后方——正后方会被首领贴图整个盖住，打完了也找不到箱子。

### 13.6 踩坑

- **`deepC` 返回的是区域局部坐标，我当世界坐标用了**，结果地脉裂口被画到了
  地图左上角的野地里。现在 `genFloor` 一律输出世界坐标：让调用方自己加偏移，
  迟早会有某一处忘掉。
- 洞口那 2 格原本铺土色，一路从门口铺进屋里，像条黄泥地毯。现在只留最外两行，
  且改用偏暖石色——一块方正黄泥铺在石板中间，读起来像进门处放了块地毯。
- 连通性自检时我拿"洞口那一行"当洪水填充起点，忘了第 2、3 层洞口是封死的，
  于是报出 120 次"不连通"。**测试自己也会错**：改成从入口房中心起手，问题消失。
- 洞里能看见墙外的草地（1 圈岩层太薄）→ 加厚到 2 圈 + 山体影。
- 玩家被同一条蛇连咬三口，屏幕叠了三条"中毒"→ 已经中毒就不再报。

### 13.7 验收

- `?dev=1`：**137 pass / 0 fail**（本批新增 27 条：生成出房间 / 布了妖物 / 每屋有火盆 /
  洞口外站得住 / 走进洞口算进洞 / 洞里的光只来自洞内 / 出洞光源恢复 /
  没清怪裂口封着 / 清完自己开 / 深入地脉到第 2 层 / 第 2 层洞口封死 / 换了一批怪 /
  第 3 层有洞主 / 洞主主动扑上来 / 大箱锁着 / 伏诛解锁 / 三件装备 / 保底精品以上 /
  给银两与精铁 / 只能开一次 / 回到地面 / 落地站得住 / 重进换一座洞 / 重排仍连通 /
  死在洞里下一趟是新洞）。
- `tools/touch.js` 手机横屏：站到裂口前「谈」键出现、点一下到第 2 层，`ok: true`。
