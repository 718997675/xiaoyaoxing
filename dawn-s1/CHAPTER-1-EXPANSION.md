## 3. 地貌分区设计

地图从 96×72 扩到 144×104 后，按九宫格切成四块，中间是青云集：

```
┌─────────────────┬─────────────────┐
│  西荒石窟        │  北坡乱葬岗      │
│  (石窟/矿道)     │  (荒坟/阴气)     │
│  Lv 8-12        │  Lv 6-10        │
├─────────────────┼─────────────────┤
│  南岭竹海        │  青云集 (安全区)  │
│  (竹林/机关)     │  店铺/任务/打坐   │
│  Lv 3-7         │                 │
└─────────────────┴─────────────────┘
         ↓ 古洞入口在地图最北 (ALTAR)
```

**连通规则**（重要，别做成"四块孤岛"）：
- 每个区至少 **2 条**通道连回青云集（一主一窄），窄道放精英怪当"关卡守卫"
- 区与区之间至少 1 条捷径，玩家跑图不用绕回村子
- 所有通道宽度 ≥ 3 格，避免玩家卡在 1 格缝隙里

**主题调性**（**待确认**，见第 7 节）：
- 南岭竹海：清幽、机关陷阱、蛇与山魈、白天安全夜里凶
- 西荒石窟：狭窄、火把照明、石傀与火鸦、地形复杂
- 北坡乱葬岗：现有内容就地扩写（阴魂 / 鬼火 / 千年树妖）

### P2 · 营地生态（"两个营地要具备生态"）

用户原话是"两个营地也要具备生态"。我的理解是**所有营地都该像个活的地方**，先做 2 个样板，再推广。

**生态 = 四件事**（缺一件就是"一堆怪站着"）：

1. **巡逻**：营地内固定路线，`patrol: [[x,y],...]`，到点转向
2. **警戒**：视野内发现玩家 → 吹哨（附近同伴一起 aggro）→ 追击 → 脱离距离后回营
3. **食物链**：食草妖（狐/蛇）被掠食者（山魈/熊）追，玩家可以"等它们打完再上"
4. **作息**：白天/夜间不同阵容（复用 `clock` 和 `phases`）

- [ ] `camps` 从 6 扩到 12，每项加 `patrol` / `alert` / `chain` / `nightTypes`
- [ ] 营地内部加"篝火 + 帐篷 + 哨塔"三类 props（视觉锚点，玩家一眼认出这是营地）
- [ ] 夜间营地：火堆变亮、怪变凶、部分怪睡觉（可偷袭，配合已有的晨雾偷袭 ×1.5）
- [ ] 3 个 tier3 精英营：加"营地首领"，打死才刷宝箱

**验收**：
- 站在营地外 100px 观察 30 秒，能看到至少 2 只怪在动（不是全静止）
- 打一只，附近 2~3 只会一起过来（吹哨生效）
- 跑开 200px 后回营，怪回到巡逻路线

## 5. 技术要点与已知坑

### 5.1 地图变大要同步改的地方

| 位置 | 为什么要改 |
|---|---|
| `MAPW` / `MAPH` 常数 | 所有 `y * MAPW + x` 的索引都依赖它 |
| `solid` / `tiles` 数组初始化 | 大小 = MAPW×MAPH |
| 地图生成循环里的散点数量 | 写死的 90 / 320 要按面积比放大，否则大图会稀 |
| 小地图绘制 | 现在按 96×72 缩放，要改成按实际尺寸比例 |
| 相机 clamp | `Math.min(MAPW*TILE - LW, ...)` 已参数化，应该自动生效，但要验 |
| `nearClear()` / `inVillage()` | 营地与村庄的排斥半径要重新算，否则新营地会压到建筑 |

### 5.2 存档兼容（必须处理）

旧存档的 `x/y` 在新地图上可能落在墙里或地图外：

```js
// load() 里，Object.assign 之后
if (!canStand(player.x, player.y)) {
  player.x = SPAWN.x; player.y = SPAWN.y;
  msg('地脉变动，已送回青云集', C.jade3);
}
```

### 5.3 性能

- 地图生成是同步的，144×104 约 2.2 倍格数，实测若 > 300ms 需要分帧
- 渲染只画视口内（`camera` 裁剪），地图变大不影响帧率，但要确认没有全图遍历的每帧循环
- `lightSources` 是全图数组 —— 夜里逐光源算光照，营地从 6 涨到 12 会翻倍，注意 `drawDayNight` 的耗时

### 5.4 测试怎么写

现有 `devtest.js` 的断言风格：
```js
T('名字', 条件, '实测值');
```
新功能照这个写，重点覆盖：
- 四区连通性（洪水填充）
- 每个营地的怪都能刷出来
- 每个首领能被打死
- 每条任务能完成
- 存档往返（存→读→状态一致）
