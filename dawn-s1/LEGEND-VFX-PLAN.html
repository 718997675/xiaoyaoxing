传奇式技能演出重构方案

研究版 · 2026-11-18 · 口径已拍板：四视觉族 / 玩法零重复不变 / 先出样片

2026-11-18 拍板结果（下面三族方案以此为准）

  • 四个视觉族：战士 = 剑 / 刀 / 枪 / 锤；法师 = 法杖 / 扇（法器意象）；道士 = 棍杖（令旗 / 魂幡意象）；刺客 = 暗器 / 双刃 / 锁链。
  • 10 兵器 ID、技能表、数值全不变 —— 法器 / 令旗 / 魂幡只做演出道具，刺客是第 4 个视觉族，不是玩法职业。
  • 玩法字段零重复保留（art-unique.js 继续卡全表），演出层允许同族共用语法，差异放进形状参数 / 入射角 / 节奏 / 命中帧。
  • 先做 4 招样片：sword_1 破锋式 / mage_1 灵珠 / staff_6 缠棍 / dart_1 飞蝗 —— 见 legend-vfx-sample.html（旧版 CINE vs 新语法逐帧对比）。
一句话结论：传奇的技能好看，不是粒子多，而是每招只做三件事——一个由判定决定的空间形状、一个主色、一个命中爆点。
我们现在把「80 招互不重复」做成了「每招多叠几层」，所以 80 招各不相同，但画面一样乱。 重构方向不是继续加特效，而是给演出立一套克制的语法，把差异放进形状参数和节奏里，不再放进层数里。

零之前、路线可行性实测（2026-11-18 下午）

「能不能直接拿传奇素材做帧动画 / 或者仿照传奇自己做帧动画」—— 两条路都实际跑了一遍，不是纸上推演。

路线实测做了什么结论
A 直接拿传奇素材 黑键 GIF → 亮度键 + flood fill 抠透明 → PNG 序列 → 预加载 Image → 逐帧 drawImage，接进样片页跑通（8/10/16 帧全部加载并渲染）。 技术可行，但素材不能直接用：① 传奇 GIF 是「角色 + 特效 + 背景」合体录像 —— 抠出来带角色、带召唤物、带别的元素（绿法阵那帧抠出来是「金翅凤凰 + 远处一个小金阵」），要干净就得逐帧人工修图；② 尺寸是给 800×600 俯视场景画的，我们是 320×180 横版侧视，等比缩小会糊、放大就糊满屏（已实测）；③ 授权不明。拿来做描摹参考极有价值，直接贴进来不行。
B 80 招各做一套帧动画 产能估算：80 招 × 14 帧 ≈ 1120 帧，且不能复制（否则又是「复制效应」）。 不可行，而且这不是传奇的做法 —— 传奇自己只有十几套基础形状，靠组合出所有技能。
C 基础形状 sprite 库 + 程序化组合 实测：2 张手绘/AI 位图（一小弯 + 一大弯月牙），靠缩放 / 位移 / 交叉淡入 / 旋转程序化补出 14 帧动画，跑进同一套渲染管线。 推荐。质感和层次碾压纯矢量；产能账是 24 套基础形状 × 8~12 帧 ≈ 240 帧覆盖全部 80 招，不是 1120 帧。

技术接入点（已核实）

  • 游戏内特效走的是 drawOverlay → CV.renderCanvas(octx, fr.prims, ...)，不是软件光栅化 rasterize —— 所以接位图只需在 renderCanvas 加一个 k:'img' 分支（drawImage），<20 行，不用动像素缓冲那套。
  • 配套需要：帧索引表（每个 sprite 记帧数 / 锚点 / 缩放）、Image 异步预加载、加载失败自动回退到矢量图元（否则素材没到位那一招就是空的）。
  • 两个必须遵守的坑：素材尺寸要按我们 320×180 的画布重新定；素材是异步的，就绪后必须触发一次重绘（否则暂停状态下首帧是空的）。
  • AI 生成可用但要人工收尾：实测能直接出「白热核心 + 橙红外焰 + 飞溅 + 辉光」的高质量月牙，但带背景色和右下角水印，需要 flood fill 抠背景 + 裁掉水印。
结论：想「借鉴传奇」，最该借鉴的不是它的像素素材，而是它的做法 —— 一套基础形状库 + 程序化组合。 路线 C 可以在不动玩法数值、不动技能表的前提下，把演出从「173 图元 / 12 色」换成「一个厚实主体 + 十余张手绘帧」。

和上一版推断的四处出入（上一版是看词条猜的，这版是看帧得到的）：
① 「传奇特效素」—— 错。传奇的单个元素又厚又大，「素」指的是元素数量少，不是尺寸小。
② 「一招一色」—— 方向对但不精确，是 1 色相 + 白高光的明度渐变，不是多色并列。
③ 上一版完全没提时长 —— 我们现在的 3~5s 比传奇慢一倍还不止，这是「乱」之外的第二个病。
④ 上一版没抓到范围招的招牌手法（多根同形落柱 + 地面法阵），也没抓到召唤物是实体素材。

一、先研究：传奇三职业到底怎么做的

查了百度百科技能词条与腾讯官方传奇站的技能说明。下面只提与「视觉实现」有关的事实，机制数值用来解释为什么那样画。

战士 武器即特效

  • 刺杀剑术：面前两格直线剑气，1 格与 2 格伤害相同，130% —— 画一条直线，不画弧。
  • 半月弯刀：身前环形半弧打全怪，70% / 3MP —— 画一道半弧，范围就是半圆。
  • 烈火剑法：火附刀 10 秒，蓄力释放、后摇长，3 级 2.6 倍，可「双烈火」 —— 亮在刀上，不在天上；蓄力期有明确光晕，命中一瞬给白点。
  • 独立起手音 / 命中音，靠声音区分阶段，不靠多画粒子。
来源：百度百科「刺杀剑术」「半月弯刀」「烈火剑法」词条

法师 起手 → 飞行 → 爆点

  • 雷电术：从天而降的雷电，命中僵直，130% / 20MP，施法间隔 1.2 秒 —— 一道光柱 + 一个白点，三段清楚。
  • 冰咆哮：3×3 范围、110% / 45MP、施法快、100% 命中、连续命中递增 —— 范围用明确的格子，不用满屏飞雪。
  • 流星火雨：连续三波火球砸 4×4 地面 —— 一波一爆点，次数即节奏。
  • 元素各占一色：雷蓝白、冰冷白、火赤金；一招只一种元素。
来源：百度百科「雷电术」「冰咆哮」「流星火雨」词条

道士 小投射物 + 状态标记

  • 灵魂火符：单体符咒，为道士主攻 —— 一张符飞过去，不是一团火。
  • 施毒术：降防 + 持续掉血 —— 视觉只在目标身上留一个小状态，不持续放烟花。
  • 召唤神兽：召唤实体随从，白 / 绿 / 淡蓝按等级 —— 强效果做成一个看得见的伙伴，不是一层特效。
  • 官方站明确把施毒、治愈、召唤列为道士核心 —— 辅助走「状态可读」，不走「画面热闹」。
来源：百度百科「召唤神兽」、腾讯传奇官方站道士技能说明

二、诊断：我们现在为什么乱

不是凭感觉，是把 cine-vfx.js 的 80 招逐帧跑出来数了：

指标克制 calm标准 standard爆发 burst问题
平均图元 / 帧170.7173.3173.3三档几乎一样 —— 分档形同虚设
平均颜色数（整招）12.012.312.7爆发只多 0.7 色，看不出高潮
每帧颜色中位数10 ~ 12（含背景网格）传奇一招通常 1 主色 + 白
≤2px 碎屑方块 / 帧50 ~ 66一半以上图元是飞舞的小像素点
特效占帧26 ~ 34 帧「全程无空档」从头动到尾，眼睛没有休息点
根因不是「各不相同」，是「每招都在堆层，而档位没真正拉开差异」。
具体四处：① STAGE_RATIO 要求 26~34 帧每帧都有东西；② 每招固定叠 skeleton + family + 专属 shapeSpec 三层； ③ TIER 的 layers/ghost/dust/trails/sparks 三档只差几个（8/11/14 火花），摊到 170 图元里看不出来； ④ DIFF 明写「五阶亮芯、最厚 13px + 光晕、26~34 帧无空档」——当初为解决「效果不明显」加过头了。
另外两套色规在打架：cine-vfx.js 的 FAMILY（剑 = jade2+gold3）和 VFX-DESIGN-80.md（剑 = jade3+paper3）对不上。

三、重构方案：把 10 兵器收进「战 / 法 / 道」三种视觉族

这不是改职业玩法——游戏里本来没有职业系统，只有 10 种兵器。这里只做「视觉族」归类：同族共用一套克制的语法，招式之间靠形状参数、方向和节奏区分。装备、数值、存档全不动。

剑 · 刀 · 枪 · 锤

米白刀光 赤血 暗金

  • 不画：碎屑星点、法阵、飘带、符文
  • 命中白芯 2 帧，其余帧无白

  • 一招只一种元素，不混色
