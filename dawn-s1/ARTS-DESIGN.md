# 招式设计总表

> 这份文档解决一件事：**每一招打出去，应该长什么样。**
>
> 它存在的理由是一次很具体的失败。P6 把 64 招补齐之后，玩家反馈"用哪个招式都感觉一样"。
> 查下来不是数值问题，是三层差异被依次抹掉了：
>
> | 层 | 64 招收敛成 | 原因 |
> |---|---|---|
> | 效果原语 `fx` | 12 种 | 设计表按"功能位"铺满，八兵器是同一个 8 格模板 |
> | 刀光形状 | **3 种**（环 / 直刺 / 弧） | `artSwingFx()` 只有三支，颜色一律取兵器家族色 |
> | 角色身体动作 | **2 种** | `execArt()` 里写死 `a0:0, a1:0` —— 武器全程定在朝向不动 |
>
> 实测：**17 招与同兵器的另一招视觉签名完全一致**。名字那一层则根本没进过机制
> ——「枪阵」是同一目标打三下，「回旋锤」是 360° 近身判定，锤没离手。
>
> 所以这份文档的第一原则是：**先写"这一招的画面"，再由画面倒推判定与动作。**
> 反过来做（先定 mul/kb 再想名字）就是上一轮走错的路。

---

## 一、四条硬规矩

每一招必须同时具备四个**互不重复**的签名。同一件兵器内，任何一个签名重复都算不合格：

1. **形状签名** —— 判定区域的几何形状（点 / 窄扇 / 宽扇 / 环 / 长条 / 扩散环 / 抛物往返 / 地面多段）
2. **动作签名** —— 角色身体与武器的运动（起手时长 + 幅度 + 方向轴 + 收势）
3. **色彩签名** —— 这一招自己的刀光色，不再一律用兵器家族色
4. **声音签名** —— 起手音 + 命中音

验收方式写在 `tools/arts.js` 里：把每招的 `(shape, pose.mode, color)` 拼成一个字符串，
**同兵器内不得出现重复**。这一条能自动跑，不靠人眼。

## 二、八兵器的性格（先写一句，其余七件待补）

| 兵器 | 一句话性格 | 核心动词 |
|---|---|---|
| 剑 | 精准与位移 —— 一次只解决一个人，但一定解决得掉 | 递、点、走 |
| 刀 | 势与连 —— 一刀比一刀重，收不住 | 劈、扫、压 |
| 枪 | 距离与线 —— 站在你能碰到的外面 | 刺、贯、挑 |
| 棍 | 周天与扫 —— 一圈都是我的 | 扫、缠、抡 |
| 双刃 | 节奏与叠 —— 快，但每一刀都轻 | 切、错、叠 |
| 法杖 | 布场与延迟 —— 现在种下的，等一会儿才收 | 种、引、封 |
| 暗器 | 层数与覆盖 —— 一枚没用，一百枚有用 | 撒、叠、覆 |
| **锤** | **重量与时机 —— 一个动作，一个结果，中间没有第二下** | **砸、撞、插** |

## 三、锤 · 重量与时机

锤的每一招都必须是"**一次性的**"：没有连段、没有多段命中、没有持续旋转。
锤的对手感受到的是"被砸中一次就完了"，而不是"被砍了很多下"。

起手要长（看得见），收招要空（打得掉），落点要实（砸下去就有东西碎）。

### 1. 碎骨锤 · 输出 · 专精 1

- **画面**：举锤过头，一记**垂直单点**下砸。落点不是一片，是**一个点**，骨屑从那一点往外炸。
- **判定**：`point` —— 极窄扇（arc 0.55）＋ 短 reach 34。打中的往往只有一个人。
- **动作**：`overhead` · a0 −1.90 → a1 +0.45 · dur 0.34 · ease **in**（慢慢蓄，猛地落）
- **表现**：落点一小圈白闪 + 4 道放射碎屑 + 地面一个凹坑贴花；命中瞬间顿帧 0.07
- **声音**：`slash`(hammer) 起手 → `forge` 命中（金属撞骨）
- **保留**：破甲 `break` 4 息

> 和「眩晕击」的区别：碎骨是**从上往下砸一个点**，眩晕是**从侧面横抡一个人**。方向轴不同。

### 2. 回旋锤 · 输出 · 专精 2

- **画面**：锤**脱手飞出去**，转一圈，**回到手上**。飞出去时人是空的。
- **判定**：`boomerang` —— 去程 200px 穿透，回程再判一次；同一目标整招只吃一次，不同目标可以吃两次。
- **动作**：`throw` —— 手臂前甩 dur 0.22（锤离手）→ 飞行 0.5 息 → `catch` 回手 0.12
- **表现**：锤的贴图沿一条外凸弧线飞出再回来，身后拖一条尘迹；回手时手上有一下接住的顿
- **声音**：`slash`(hammer) → 飞行时 `boomerang` 呼啸 → 回手 `hit`

> 这是锤唯一一招"武器离手"。它存在的意义是让玩家知道：**锤也可以不砸，可以扔。**

### 3. 震地 · 清场 · 专精 3

- **画面**：双手举锤过顶，砸地。**一圈冲击波从脚下往外扩**，不是"半径内立刻受伤"。
- **判定**：`shockwave` —— 环形，半径 84，**波以 240px/息 向外扩**，伤害在波前到达时结算。
- **动作**：`slam` · a0 −2.60 → a1 +1.00 · dur 0.42 · ease in ＋ 落地时身体下沉 4px
- **表现**：地面一圈尘环扩散（有速度）+ 中心蛛网裂纹；屏幕震 8px、顿帧 0.10
- **声音**：`slash`(hammer) → `quake`（新增：低频 + 尘土）

> 和「碎骨锤」的区别：碎骨是**一个点**，震地是**一个正在扩大的环**。远处的人晚半拍才飞。

### 4. 地裂 · 清场 · 专精 5

- **画面**：单手砸地，一道裂缝从脚下**向正前方逐段裂开**，边裂边冒热气。
- **判定**：`zone` line × 4（保留），但四段**依次**出现，间隔 0.08 息。
- **动作**：`slamLow` · a0 −1.50 → a1 +0.80 · dur 0.30 · ease in，落地后**保持前倾 0.4 息**（收招空档）
- **表现**：四段裂缝依次亮起 + 碎石 + 焦痕；裂缝边缘持续冒细烟
- **声音**：`slash`(hammer) → `quake`（短）

> 这招原来的判定就是对的（四段向前的线），错的只是它"四段同时刷出来"。

### 5. 冲锋锤 · 位移 · 专精 6

- **画面**：低头，把锤横在身前，整个人撞出去。**撞到第一个人就停**。
- **判定**：`charge` —— 直线冲 84px，**撞到第一个敌人即停**并造成大击退；没撞到人则冲满全程。
- **动作**：`charge` —— 低身（身体下沉 3px）前冲，锤在正前方；撞上时有一个明显的"顿"
- **表现**：冲过的地面留一道尘线；撞上时前方爆一圈尘 + 震屏 5px
- **声音**：`dash` 起手 → `hit`(重) 撞上

> 现在所有 `dash` 都穿过所有敌人。"会停"这件事才是"冲锋"有重量的原因。

### 6. 眩晕击 · 控制 · 专精 8

- **画面**：**横抡**，从侧后抡到正前，砸在太阳穴上。只打一个人。
- **判定**：`point` 变体 —— 窄扇（arc 1.0）但**只取最近的一个目标**，必晕 2 息。
- **动作**：`sideSwing` · a0 −2.20 → a1 +0.25 · dur 0.30 · ease in（**水平面**，不是上下）
- **表现**：命中时目标头顶一圈星（既有眩晕表现）+ 一记短促白闪；被砸中的那一个会被打得侧翻
- **声音**：`slash`(hammer) → `forge` + `shield` 叠（闷响）

### 7. 铁壁 · 增益 · 专精 10

- **画面**：把锤**往地上一插**，人半蹲在锤后面。八息。
- **判定**：`buff`（保留：减伤 20% + 反弹 30%）
- **动作**：`plant` —— 插下 dur 0.28，然后**保持半蹲姿态** 8 息（不是站着不动）
- **表现**：锤立在地上（独立贴图，不跟手）+ 人后撤半步；有攻击打上来时锤面闪一下
- **声音**：`forge`（插地）→ 每次反弹 `shield`

> 增益类招式现在**完全没有表现** —— 玩家看不出自己处于什么状态。这一招是这条规矩的样板。

### 8. 开天辟地 · 特色 · 专精 4

- **画面**：举锤过顶，**蓄力半息**（人几乎不动），然后一记**纵向巨劈**，前方裂开一条笔直的巨口。
- **判定**：`cleave` —— 正前方长条（长 132、宽 58），沿路径全中，中心 1.5 倍。
- **动作**：`overheadBig` · a0 −2.70 → a1 +1.20 · dur 0.62 · ease in 极强（前 0.42 息几乎不动）
- **表现**：一条纵向白光刃从头顶劈到地面 → 地面裂开一条长缝 → 尘柱 + 屏幕重震 12px + 顿帧 0.14
- **声音**：`windup` 蓄力 → `thunder2` 劈下 → `quake` 落地

> 现在它是 360° 圈身、半径 130。**开天辟地是一条线，不是一个圆。**

## 五、为此需要的表现层能力

### 5.1 `pose` 字段（新增，招式自带动作）

现在 `execArt()` 写死一句：

```js
sw: { mode: a.fx === 'proj' ? 'thrust' : 'swing', a0: 0, a1: 0, dur: 0.22 }
```

`a0 = a1 = 0` 意味着 `ang` 恒等于 `base` —— **武器一动不动**。改成读招式自己的 `pose`：

```js
pose: { mode: 'overhead', a0: -1.90, a1: 0.45, dur: 0.34, ease: 'in' }
```

- `mode`：`swing` / `thrust` / `ring` / `cast`（既有四种）
  ＋ `overhead` / `overheadBig` / `slam` / `slamLow` / `sideSwing` / `throw` / `plant` / `charge`
- `ease`：`out`（快起慢收，普攻用）/ `in`（慢蓄猛落，重武器用）/ `both`
- `hold`：收招后保持这个姿势多少息（地裂落地后前倾 0.4 息）
- 不写 `pose` 的招式退回旧行为，其余 56 招不受影响

### 5.2 `artSwingFx()` 从 3 形扩到 11 形

| 形状 | 用在哪 | 画法 |
|---|---|---|
| `point` | 碎骨锤 | 落点小爆点 + 4 道放射 + 头顶到落点的纵向刃光 |
| `shockwave` | 震地 | 中心爆点 + 10 道放射尘（环本体由 `waves` 按真实半径画） |
| `crack` | 地裂 | 多段依次亮起的裂缝（带 `delay`，一段晚 0.08 息） |
| `cleave` | 开天辟地 | 长条纵向刃光 + 沿路的地面长缝 |
| `boomerang` | 回旋锤 | 沿路的光点 + 飞行时每 40ms 留一个尘点（轨迹尾巴） |
| `sideArc` | 眩晕击 | 水平粗弧 + 侧向尘 |
| `chargeLine` | 冲锋锤 | 一条细长擦痕 + 五粒扬尘（不用 thrust 锥：锥形读作"枪尖捅出去"） |
| `plant` | 铁壁 | 脚下一小圈尘 |
| `arc` / `ring` / `thrust` | 既有 56 招 | 原样保留 |

ghost 上新增四个字段：`dot`（爆点半径）、`line {ang,len,w}`（有方向的刃光）、
`grow [r0,r1]`（环从 r0 长到 r1）、`delay`（秒，先等这么久再淡出）。

> 原计划里还有一条 `overheadArc`（"从头顶到落点的纵向刃光"）。实现时发现它和 `point`
> 画的是同一件事 —— 碎骨锤本来就是"过顶下砸一个点"，那道理应画在 `point` 里，
> 于是把这条并进 `point`，没有单独做。**形状表跟着实现改，不是实现跟着表硬凑。**

### 5.3 四个新效果原语

| 原语 | 语义 | 谁会用 |
|---|---|---|
| `boomerang` | 抛出去、飞回来，去回各判一次 | 回旋锤；将来刀的「飞刀」、暗器的「回旋镖」 |
| `shockwave` | 环形但**有扩散速度**，按距离延迟结算 | 震地；将来锤/棍的落地技 |
| `charge` | 直线位移，**撞到第一个就停** | 冲锋锤；将来枪的「突刺」、刀的「突进」 |
| `cleave` | 正前方长条，沿路径全中 | 开天辟地；将来枪的「贯甲」、剑的「一闪」 |

这四个都是**可复用的**，不是为锤专门造的。枪要「贯甲刺」得用 `cleave`，
刀要「突进」得用 `charge` —— 先做出来，后面七件兵器省一遍工。

### 5.4 两个新音效

- `quake`：低频震动 + 尘土（震地 / 地裂 / 开天辟地落地）
- `boomerang`：带多普勒的呼啸（回旋锤去程高、回程低）

## 六、验收标准

改完必须同时满足：

1. **八个签名互不重复**（自检自动跑，见第一节）
2. **每招的起手时长可感知**：碎骨 0.34 / 震地 0.42 / 开天 0.62 —— 慢的那招必须真的慢
3. **平衡不破**：八招全开一轮 DPS ≤ 普攻 2.8 倍（`tools/arts.js` 既有口径，不改）
4. **动作能截图看出来**：同一位置连拍八张，八张的武器角度必须各不相同
5. **旧断言全绿**：`tools/arts.js` 现有 89 条一条不删，只加不减

| 2 | ✅ 起手 0.22 / 0.28 / 0.30 / 0.34 / 0.42 / 0.62 六档 |

## 七、其余七件兵器

锤做完了。锤这一轮造出来的东西，后面七件可以直接用：

- `pose` 字段与 12 种动作（`overhead` / `sideSwing` / `throw` / `plant` / `charge` …）
- 9 种刀光形状 + `color` 逐招上色
- 四个新原语 `boomerang` / `shockwave` / `charge` / `cleave`
- 两个新音效 `quake` / `boomerang`
- `artShape()` / `artPose()` / `artColor()` 三个推导函数（运行时与自检共用）

接下来按同一套格式往下写：先一句性格，再八招的「画面 → 判定 → 动作 → 表现 → 声音」，
再列出这件兵器需要的新能力（**能不新增就不新增，优先复用上面这四样**）。

顺序：**枪 → 刀 → 棍 → 剑 → 双刃 → 法杖 → 暗器**。
枪和刀最需要 `cleave` / `charge`，接着做能立刻复用；暗器现在的形状递进已经是对的，改动最小，放最后。

每做完一件，`tools/arts.js` 里那条「签名撞车的兵器只剩 N 件」的 N 就减一，最后必须是 0。
