## 二、已经踩出来的硬数据（不要重犯）

### 2.1 传奇特效的真实规律（40+ 个实拍 GIF 逐帧归纳）
- **① 一招一形** —— 形状由判定决定，不叠第二形状
- **② 一招一色相 + 1 白高光** —— 火焰是**红→橙→黄同色相明度渐变**，不是多色并列
- **③ 主体要厚** —— 刀光是 8~13px 实心楔形带白芯；元素少但单个必须大
- **④ 三段节奏** —— 起手 1/3 帧画面留空 → 主体一帧到全盛 → 消散碎 8~14 粒
- **⑤ 碎屑只在主体边缘 ≤14**；伤害数字周围留空；受击不用全身白闪
- **⑥ 一招 10~18 帧**（传奇主流 8~14 帧）—— **我们现在的 90~120 帧慢一倍还不止**

> 词条推演版曾有四处结论被实拍推翻，其中最关键的一条：
> **「传奇特效素」是错的** —— 传奇元素**又厚又大**，「素」指**元素数量少**，不是尺寸小。

### 2.2 我们「乱」的量化根因
80 招逐帧统计：`calm / standard / burst` 三档图元/帧 = **170.7 / 173.3 / 173.3**，颜色 = **12.0 / 12.3 / 12.7** —— 分档形同虚设；每帧另有 **50~66 个 ≤2px 碎屑**，26~34 帧全程无空档。

### 2.3 路线 A 的三个硬伤（都实测过）
1. **传奇 GIF 是「角色 + 特效 + 背景」合体录像** —— 抠出来带角色/召唤物/别的元素
   （绿法阵那帧抠出来是「金翅凤凰 + 远处一个小金阵」），要干净得逐帧人工修图。
2. **素材是给 800×600 俯视场景画的**，我们是 320×180 横版侧视 —— 等比缩小会糊，放大糊满屏。
3. **授权不明** → 因此走 A′（自产原创）而非直接搬。

### 2.4 技术接入点（已核实）
- 游戏内特效走 `drawOverlay → CV.renderCanvas(octx, fr.prims, ...)`，**不是**软件光栅 `rasterize`。
  → 接位图只需在 `renderCanvas` 加一个 `k:'img'` 分支（`drawImage`），**<20 行**。
- 配套需要：帧索引表（帧数/锚点/缩放）、Image 异步预加载、**加载失败自动回退矢量图元**。
- 两个必踩的坑：素材尺寸要**按我们 320×180 画布重新定**；素材异步，**就绪后必须触发重绘**
  （否则 QS 带 `f` 暂停时首帧是空的）。

## 五、不能忘的约束

- **10 兵器 ID、技能表、玩法数值全部不动**；法器/令旗/魂幡只作演出意象；
  刺客是**视觉族**，不是玩法职业。
- 玩法层零重复（`shape/pose/snd/hitSnd/color` 全表两两不同）继续由 `art-unique.js` 卡。
- 演出层**允许同族共用语法**，差异放形状参数/入射角/节奏/命中帧。
- 贴地平面一律 `fy = 0.32` 压扁椭圆；枪身不压扁。
- 演出时长 3~5s 是**旧口径**；传奇实证是 **10~18 帧**，两者需要拍板统一。
- 每批 4 招、审完再下一批；禁止写通用组件包/模板（用户原话：「一推广就会产生复制效应」）。

## 六、抓取与工具备忘

- 真实传奇 GIF 抓法：`https://image.so.com/j?q=<URL编码>` → 正则 `"img":"(https?:[^"]+)"` → 过滤 `.gif` → curl 下载。
  **同一 IP 连打会被限流**（返回 3.5KB 空壳），每次请求间隔 8~20s 重试，最多 5 次。
  百度图片 acjson 被反爬挡；百度百科/搜狗图/论坛帖不出直链。
- 截图：`env PAGE=xxx.html QS="tab=N&f=M&x=1" node tools/run.js shot out.png 1280 1080`
- 自检：`env PAGE=art-motion-preview.html node tools/run.js eval tools/art-motion.js`（**必须带 `PAGE=`**）
- 规范表自检：`node tools/art-spec-check.js`（Node 直跑）
- bash 里中文文件名传给 node/curl 易出问题，**文件改名用 python**。
- PIL 在本机 site-packages 是空的，`python -m pip install --target .pylibs pillow` 可用（用完删）。
