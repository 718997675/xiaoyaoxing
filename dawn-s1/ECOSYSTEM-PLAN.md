# 逍遥行 · 世界生态升级方案（S3）

> 目标：把「一张刷怪地图」变成「一个会自己过日子的地方」。
> 借鉴 9th Dawn 的**机制思路**（昼夜、作息、店铺、聚落），表达层全部原创中国仙侠。
> 本文是下一阶段的施工图，不是许愿池——每一项都标了实现成本与验收标准。

---

## 1. 先想清楚：玩家为什么会觉得"这个世界是真的"

不是靠更多地图，而是靠三件事：

| 要素 | 玩家心里的那句话 | 对应设计 |
|---|---|---|
| **规律** | "天黑了，怪会变，店会关" | 昼夜循环 + NPC 作息表 |
| **被打破** | "今晚好像不太一样" | 天气 / 夜行精英 / 传闻事件 |
| **被记住** | "他记得我买过药" | 声望 + NPC 记忆 + 说书人 |

一条铁律：**任何"生态"如果玩家看不见，就是白做。**
所以每加一个系统，必须同时给它一个"可视化锚点"：钟声、灯光、摊位收摊、NPC 走位、招牌灯灭。

---

## 2. 昼夜循环（第一个做，性价比最高）

### 2.1 参数

- 一"日" = 14 分钟真实时间：**卯时 2 分（晨雾）→ 午时 6 分（白昼）→ 酉时 2 分（黄昏）→ 子时 4 分（夜）**
- HUD 左上角一个日晷小图标 + "酉时·黄昏"文字，跨时段时敲一声钟（程序化音效）+ 打一条屏中提示
- 土地庙/客栈可"打坐至下一时辰"，直接推进时间（把等待变成主动选择）

### 2.2 视觉（成本最低、收益最大）

- 整屏色罩：晨 `rgba(180,210,220,.10)`、昼 无、黄昏 `rgba(200,110,60,.16)`、夜 `rgba(20,30,70,.42)`
- 夜里的光源用加法叠加：石灯、营火、客栈窗户、玩家手持法宝（法宝越高稀有度光圈越大）
- 夜间给玩家一圈"可视半径"（中心亮、边缘压暗）——这一条就能把"夜"变成压迫感
- 怪物在夜里的剪影反光（阴魂/火鸦自带发光）

### 2.3 玩法联动（关键：让时间有意义）

| 时段 | 变化 |
|---|---|
| 晨 | 山贼在营地睡觉（可偷袭，伤害×1.5），掉落不变 |
| 昼 | 常规；商队/货郎出现 |
| 黄昏 | 狼群/山魈成群出动，攻击性 +30% |
| 夜 | 阴魂、火鸦、影刺客刷新率大幅上升；**稀有掉落率 +40%**；土地庙外不安全 |
| 雷雨夜 | 天雷诀伤害 +50%、冷却 -20%；火鸦变弱 |

**这就把"刷装备"从无脑循环变成了风险决策**：想刷仙品，就夜里出门。

## 3. 青云集（第一个村庄 / 存档枢纽）

位置：青云野南侧，土地庙往南 20 格，一片有围墙的聚落（约 30×22 格）。

| 建筑 | 功能 | 是否可进入 |
|---|---|---|
| 客栈（悦来居） | **存档 / 回满气血真气 / 打坐过夜（推进时间，20 银两）/ 听说书** | 可进入（24×14 室内小图） |
| 药铺（回春堂） | 买回春丹、解毒散、回气散；卖材料 | 可进入 |
| 铁匠铺 | 强化 / 重铸（把现在的"铁匠台"搬进来，庙里保留简易版） | 可进入 |
| 酒馆（醉仙楼） | 卖酒（临时 buff）、打听传闻（在地图标记一个 POI） | 可进入 |
| 民居 ×3 | 纯氛围，夜里亮灯、有炊烟 | 不可进入（门牌提示"主人不在"） |

**设计取舍**：先做 **2 个可进入室内**（客栈、药铺）+ 2 个纯 UI 摊位（铁匠、酒馆）。
室内用独立小地图（24×14），进门淡入淡出，成本远低于"无缝室内"。

### 3.1 客栈 = 存档点，但要"有代价"

- 免费：回满气血真气（不能存档）
- 20 银两：住一晚 → 推进到卯时、存档、刷新商店库存与野怪
- 10% 概率触发夜话事件：被偷（损失少量银两）/ 有人送信（指引一个藏宝点）/ 梦见功法（+1 参悟点，稀有）

这条把"存档"从功能变成了**节奏器**：玩家会自然地"打一晚—住店—再出门"。

## 4. NPC 生态：让 NPC 有自己的日程

### 4.1 状态机（够用就好）

```
idle(在岗位) → walk(按日程走到下一个路径点) → work(摊位前) → talk(玩家交互时暂停日程) → sleep(夜里回家消失)
```

每个 NPC 只有 **3~5 个路径点**（家 → 岗位 → 酒馆 → 家），一条时间表：

| 时辰 | 药铺掌柜 | 酒馆老板 | 铁匠 | 说书人 | 守夜人 |
|---|---|---|---|---|---|
| 卯 | 家→铺子 | 睡觉 | 睡觉 | 睡觉 | 回家 |
| 午 | 铺子里 | 铺子里 | 铺子里 | 茶馆 | 睡觉 |
| 酉 | 铺子里 | 铺子里 | 收摊 | 酒馆说书 | 起床 |
| 子 | **回家（铺子关门）** | 铺子里（最热闹） | 家 | 酒馆 | 巡夜 |

> 只有"关门"这一件事被玩家感知到，作息就已经成立了。
> 所以第一批 NPC 只需要实现"到点消失/到点出现" + 一句台词，不需要真的寻路。

### 4.2 NPC 清单（12 个，先做 8 个）

| NPC | 作用 | 一句台词示例 |
|---|---|---|
| 药铺掌柜 · 孙婆婆 | 卖药 | "夜里出门，带瓶解毒散。赤练蛇不咬死人，毒能。" |
| 酒馆老板 · 胡三 | 卖酒 / 传闻 | "西边乱葬岗，昨夜有人看见灯自己走。" |
| 铁匠 · 石头 | 强化/重铸 | "你这刀，再淬一次就废了。要试？" |
| 说书人 · 柳先生 | 传唱你的战绩 / 引导 | "诸位，这位少侠昨日斩了黑风寨三十七人。" |
| 守夜人 · 老陈 | 夜间任务/情报 | "天黑别往北边去。听劝。" |
| 货郎 · 阿福 | 随机稀有货（每小时刷新） | "客官，这面镜子……来路不太正。" |
| 村民 ×3 | 氛围 / 评论你的装备 | "哟，这身甲，得不少银子吧？" |
| 小孩 | 跟随你一段路 / 恶作剧 | "大侠大侠，你会飞吗？" |
| 猫、狗、鸡 | 纯氛围，会跑会叫 | — |

### 4.3 对话与交易

- 对话框：宣纸面板 + 打字机效果，最多 3 行，选项 ≤ 4 个（买 / 卖 / 打听 / 告辞）
- 交易面板复用现有行囊 UI（左店右包），加价格与声望折扣
- **传闻系统**：打听 → 得到一句含糊线索 + 小地图上出现一个问号 POI，走到附近变成宝箱/精英/地宫入口

传闻是"低成本任务系统"：不用做任务链，就能驱动玩家去探索。

## 5. 世界记得你（声望与记忆）

- **侠名**（-100 ~ +100）：杀山贼 +1，杀精英 +3，误伤村民 -15，在村里放技能 -1
- 侠名影响：价格折扣（+50 侠名 → 9 折）、NPC 称呼（"少侠"/"这位客官"/"煞星"）、部分对话解锁
- **NPC 记忆**：每个 NPC 记 3 个 flag（见过 / 买过 / 帮过），台词按 flag 变化
- **说书人传唱**：击杀数、最高连击、最好装备 → 变成说书段子（"三十七连斩"），这是最便宜的存在感
- 夜里路过的村民会举灯照你一下再走开——一个 0.3 秒的动作，胜过十句台词

**反直觉的地方（下一批别再踩）**：色罩**不能**按"透明度滤镜"的思路给低 alpha。青绿底（46,107,103）上叠 alpha 0.17 的橙色，结果只是变成脏灰绿，肉眼完全读不出黄昏。必须给到 **0.4~0.7** 的混合比、并且让色罩的红通道**高于**底色的绿通道，才会真的"变暖"。同理夜晚要 0.7 才压得住，0.4 时看着像"水下"而不是"天黑"。

**另一个坑**：`KEYS` 关键帧的首尾必须同值。少写 `t: 1.000` 那一帧的话，`lightAt()` 在 t>0.975 时会落到兜底分支返回纯白 a=0 —— 每天最后 21 秒会闪一下白。

## 8. 风险与我的取舍建议

1. **不要做无缝室内**：一栋房子一套 tilemap，工作量是室内的 5 倍，玩家感知却差不多。
2. **不要做全动态寻路**：NPC 走固定路径点，卡住了就"瞬移回岗位"，玩家看不出来。
3. **不要一开始就写对话树**：先做"一句台词 + 4 个选项"，能撑住 90% 的体验。
4. **昼夜速度宁快勿慢**：14 分钟一日，玩家一局能经历两次天黑，才感受得到。
5. **别让生态打断刷宝**：所有商店/对话都能一键退出，任何时候按 Esc 回到战斗。
